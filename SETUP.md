# Glance

A menu bar clock that answers screenshots. Needs macOS 14 (Sonoma) or newer.

## Install (once)

1. On the Mac, sign in at github.com, then open:
   https://github.com/lorenzobiscotti-create/glance/releases/latest/download/Glance.zip
2. Double-click `Glance.zip`, then drag **Glance** into **Applications**.
3. Open Glance. macOS says it can't check it. Click **Done**, go to
   **System Settings → Privacy & Security**, scroll down and click **Open Anyway**.
4. Copy your API key (from console.anthropic.com → API Keys). Glance saves it by itself
   and shows **✓ API key saved**. No pasting needed.
5. **System Settings → Control Center → Clock Options → Style: Analog.**
   Hold ⌘ and drag Glance's time where you want it.

## Use

1. Press **⌃⇧⌘4** (Control + Shift + Command + 4) and drag a box.
2. A small `·` after the time means it's thinking.
3. The answer replaces the time for 6 seconds. Click the time to see all of it.

Turn **Answer Screenshots** off in Glance's menu to pause it.
Cost: about 1–2 cents per answer.
